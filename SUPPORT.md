## Questions

Open a [GitHub issue](https://github.com/sebastienrousseau/passmcp-action/issues)
for anything about running passmcp in a pipeline; a blank issue is fine
when no template fits. A question about a verdict, why passmcp judged a
server the way it did, belongs in
[passmcp's issues](https://github.com/sebastienrousseau/passmcp/issues).
Neither repository has Discussions.

## Bugs and feature requests

[GitHub Issues](https://github.com/sebastienrousseau/passmcp-action/issues),
using the templates. A good report includes the workflow step, the
action version, the step log with the token redacted, and the
`report.txt` from the report directory.

## Security

**Do not open a public issue for a vulnerability.** Follow the private
reporting process in [SECURITY.md](SECURITY.md).

## Response expectations

passmcp-action is maintained by one person alongside other work. Issues are
read within a week; security reports are prioritised per the SLA in
SECURITY.md. There is no commercial support offering.
