## Highlights ⭐️

* **passmcp in GitHub Actions**: `uses: sebastienrousseau/passmcp-action@v0` evaluates an MCP server on every push and fails the build on the findings you choose.
* **GitLab CI too**: `templates/passmcp.gitlab-ci.yml` runs the same check from the same image.
* **Pinned by digest**: both run passmcp 0.0.1's signed release image by its digest, and the token is never placed on a command line.
