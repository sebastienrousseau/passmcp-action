## Highlights ⭐️

* **In lockstep with passmcp 0.0.8**, the family's eighth release: the action and the GitLab template run passmcp 0.0.8's release image, pinned by its digest.
* **The action's description no longer counts passmcp's checks**: it said 120 checks while passmcp 0.0.7 has 138, and a number there goes stale with every passmcp release that adds one; it now says "checks in nine phases", as the README's family table does.
* **Questions go to issues, and a change comes with a test**: SUPPORT.md and the issue chooser no longer send questions to GitHub Discussions, which are not enabled on this repository, and CONTRIBUTING.md and the pull request template ask for a bats case that fails without the change.
